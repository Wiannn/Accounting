# 公司记账

网页记账应用，面向仓储物流公司的日常账务管理，手机优先设计。数据保存在浏览器本地（IndexedDB），不联网、不上云，可离线使用。打开默认进入「记一笔」，底部导航共四页：记一笔 / 客户 / 员工 / 设置。

在线访问：<https://wiannn.github.io/Accounting/>

安卓版下载：<https://github.com/Wiannn/Accounting/releases/latest>

## 功能

### 记一笔（流水总账）
- 月账本视图：‹ › 切换月份，滑动切月（滑到底继续下滑 → 上个月；滑到顶继续上拉 → 下个月）
- 当月收入（绿色边框）：点击查看各客户收入、金额与占比
- 当月支出（黄色边框）：点击查看仓库 / 车队等主分类汇总；挂账、待报销不计入支出
- 搜索框：搜索**全部月份**的收支，支持客户、分类、备注、金额、日期关键词；清空恢复当月视图
- 流水按日分组，点击条目可编辑**日期、金额、备注**或删除
- 右下角「+」打开记账抽屉页，分支出 / 收入；顶部返回键与客户管理页样式一致，并避开手机系统状态栏：
  - 支出：主分类（仓库 / 车队 / 工资）+ 子分类，付款状态 现结 / 挂账 / 待报销；主分类为「车队」时可选关联司机
  - 子分类旁「+」可自行新增，保存后长期保留
  - 收入：选客户 + 费用类型（进仓费 / 打印费，可点「+」新增自定义类型）+ 日期 + 金额，自动计入该客户的现结收入
- 挂账 / 待报销条目：登记付款 / 确认报销后按所选日期计入支出
- 账单收款不会出现在这里：客户月账单的收款只记在客户账单明细，不计入记一笔的流水与收入合计
- 保存后自动跳转到记录所在月份，滚动定位并高亮新记录

### 客户
- 顶部卡片：**本年收入**（绿色边框，点击看各客户本年收入排名与占比）、**待收总额**（点击看各客户待收排名，按待收金额从高到低）、**添加客户月账单**、**客户管理**（新增 / 重命名 / 删除）
- 月账单为独立应收台账：只需客户、月份、金额，与收支无关；收款时才自动生成收入
- 账单列表按客户折叠分组：组头显示张数、待收情况、现结收入、欠款金额；默认只展示待收与部分收款账单
- 展开客户组可进入「账单明细」页面：
  - 顶部汇总：所选年份的现结 / 应收 / 已收 / 待收欠款；已收按账期汇总实际收款，包含部分收款账单
  - 应收账单表：账期、金额、待收、收款状态、结账日期、开票状态、备注、账单附件
  - **双击账单行**可修改账期、账单金额、待收金额、结账日期、开票状态、备注
  - 账单附件支持上传 Excel 并在页内直接预览；登记收款（支持分次）、开票
- 客户组内「收费标准」弹窗：查看业务、联系方式、现结与月结收费
- 收入统计口径：收入流水 + 收款台账合并去重；收款日期为空时按应收账期归月

### 员工
- 顶部按钮：**员工管理**（新增、在职 / 离职、删除）、**生成月工资单**（选月份、员工、金额、缺勤天数），均为弹窗操作
- 工资单列表：按姓名搜索、按月份 / 状态筛选
- 工资状态：待发 / 部分发放 / 已发，支持多次发放与缺勤记录

### 设置
- 导出 Excel 报表，工作表包括：收支明细、应收台账、收款记录、发票台账、工资表；可按月份筛选或导出全部
- **导出客户账单**：选择某个客户，一键导出该客户全部数据（含备注）：
  - 「月账单」：账期、账单金额、已收、待收、收款状态、开票状态、备注
  - 「日收入」：日期、费用类型、金额、备注（记一笔的现结收入）
- 上传 Excel 导入现结收入：
  - 识别列：客户（无客户列时取**文件名**为客户名）、日期（支持「委托日期」「装箱日期」等表头）、进仓费金额
  - **委托编号 / 进仓编号**自动写入备注并保存为业务编号，支持合并单元格、多行记录、多工作表一次导入
  - 有编号时按「客户 + 业务编号」判重；同客户、同日期、同金额但编号不同的记录均可导入，文件内重复编号也会跳过
  - 无编号但疑似重复的记录默认不勾选，可在预览中手动选择；勾选变化时同步更新导入条数、金额和新建客户数
  - 预览确认后导入：自动新建客户、无效行标红
- 备份与恢复：导出 / 导入 JSON 备份文件；恢复覆盖当前数据前会自动生成安全备份

## 技术说明
- 纯前端静态应用，无需构建：`index.html`（页面结构）、`assets/css/app.css`（样式）、`assets/js/app.js`（逻辑），引用带版本号参数避免旧缓存
- Excel 导出 / 导入依赖 `assets/vendor/xlsx.min.js`（SheetJS），按需加载，不影响页面打开速度
- 数据存储：浏览器 IndexedDB（库名 `company-ledger`），各设备、各浏览器数据独立，不跨设备同步
- 部署：GitHub Pages，正式网页入口 `index.html` 保留在仓库根目录
- 资源目录：`assets/css/`、`assets/js/`、`assets/vendor/` 分别存放样式、业务逻辑和第三方库；`assets/icons/` 存放 PWA 图标，`assets/favicon.ico` 用于浏览器标签页
- 同步脚本会将入口文件、离线配置和 `assets/` 一并复制到 `www/` 和安卓资源
- 安卓：Capacitor 7，启用系统栏自动边距；主页面、记账抽屉和弹窗同时适配顶部与底部安全区

## 数据安全
- 数据仅保存在当前浏览器中，清理浏览器数据会导致数据丢失
- 建议定期在「设置 → 备份与恢复」导出备份文件，存放到 U 盘或微信文件助手
- 恢复前校验备份版本、记录 ID、关键字段和工资金额；全部清空与写入在同一事务中完成，失败时整体回滚
- 恢复前自动导出当前数据，备份生成失败则取消恢复
- 跨设备搬数据：旧设备导出备份 → 新设备导入备份

## 本地运行
- 网页：直接用浏览器打开 `index.html`，无需任何构建或服务端。
- 安卓资源同步：首次运行先执行 `npm ci`，之后使用 `npm run cap:sync` 同步网页和 Capacitor 配置。

## 发布 APK
1. 更新 `android/app/build.gradle`、`package.json` 和 `package-lock.json` 中的版本号，提交并推送 main。
2. 创建带更新明细的附注标签，再推送标签触发构建：

   ```bash
   git tag -a --cleanup=verbatim v1.0.5 -m "公司记账 v1.0.5" -m "## 更新明细
   - 新增或修复内容一
   - 新增或修复内容二
   - 数据与升级注意事项"
   git push origin v1.0.5
   ```

标签正文会原样写入 GitHub Release。没有更新正文的标签会在构建前停止发布；正式发布默认设为 Latest，不再标记 Pre-release。
