# 公司记账

网页记账应用，面向仓储物流公司的日常账务管理，手机优先设计。数据保存在浏览器本地（IndexedDB），不联网、不上云，可离线使用。打开默认进入「记一笔」，底部导航共四页：记一笔 / 客户 / 员工 / 设置。

在线访问：<https://wiannn.github.io/Accounting/>

## 功能

### 记一笔（流水总账）
- 月账本视图：‹ › 切换月份，滑动切月（滑到底继续下滑 → 上个月；滑到顶继续上拉 → 下个月）
- 当月收入（绿色边框）：点击查看各客户收入、金额与占比
- 当月支出（黄色边框）：点击查看仓库 / 车队等主分类汇总；挂账、待报销不计入支出
- 搜索框：搜索**全部月份**的收支，支持客户、分类、备注、金额、日期关键词；清空恢复当月视图
- 流水按日分组，点击条目可编辑**日期、金额、备注**或删除
- 右下角「+」记账，弹窗分支出 / 收入：
  - 支出：主分类（仓库 / 车队 / 其他）+ 子分类，付款状态 现结 / 挂账 / 待报销
  - 收入：选客户 + 费用类型（进仓费 / 打印费）+ 日期 + 金额，自动计入该客户的现结收入
- 挂账 / 待报销条目：登记付款 / 确认报销后按所选日期计入支出
- 保存后自动跳转到记录所在月份，滚动定位并高亮新记录

### 客户
- 顶部卡片：**本年收入**（绿色边框，点击看各客户本年收入排名与占比）、**待收总额**、**添加客户月账单**、**客户管理**（新增 / 重命名 / 删除）
- 月账单为独立应收台账：只需客户、月份、金额，与收支无关；收款时才自动生成收入
- 账单列表按客户折叠分组：组头显示张数、待收情况、现结收入、欠款金额；默认只展示待收与部分收款账单
- 展开客户组可进入「账单明细」页面：查看全部应收账单、现结收入，登记收款（支持分次）、开票
- 客户组内「收费标准」弹窗：查看业务、联系方式、现结与月结收费
- 收入统计口径：收入流水 + 收款台账合并去重；收款日期为空时按应收账期归月

### 员工
- 顶部按钮：**员工管理**（新增、在职 / 离职、删除）、**生成月工资单**（选月份、员工、金额、缺勤天数），均为弹窗操作
- 工资单列表：按姓名搜索、按月份 / 状态筛选
- 工资状态：待发 / 部分发放 / 已发，支持多次发放与缺勤记录

### 设置
- 导出 Excel 报表，工作表包括：收入、支出-仓库、支出-车队、支出-其他、应收台账（先按客户再按月份排序）、收款记录、发票台账、工资表，各表带合计行
- 上传 Excel 导入现结收入：
  - 识别列：客户（无客户列时取**文件名**为客户名）、日期（支持「委托日期」「装箱日期」等表头）、进仓费金额
  - **委托编号 / 进仓编号**自动写入备注，支持合并单元格、多行记录、多工作表一次导入
  - 预览确认后导入：自动新建客户、重复记录自动跳过、无效行标红
- 备份与恢复：导出 / 导入 JSON 备份文件

## 技术说明
- 纯前端静态应用，无需构建：`index.html`（页面结构）、`app.css`（样式）、`app.js`（逻辑），引用带版本号参数避免旧缓存
- Excel 导出 / 导入依赖 `xlsx.min.js`（SheetJS），与 `index.html` 同目录，按需加载，不影响页面打开速度
- 数据存储：浏览器 IndexedDB（库名 `company-ledger`），各设备、各浏览器数据独立，不跨设备同步
- 部署：GitHub Pages，上述文件放在仓库根目录

## 数据安全
- 数据仅保存在当前浏览器中，清理浏览器数据会导致数据丢失
- 建议定期在「设置 → 备份与恢复」导出备份文件，存放到 U 盘或微信文件助手
- 跨设备搬数据：旧设备导出备份 → 新设备导入备份

## 本地运行
直接用浏览器打开 `index.html` 即可，无需任何构建或服务端。
