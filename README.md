# 公司记账

单文件网页记账应用，面向仓储物流公司的日常账务管理。数据保存在浏览器本地（IndexedDB），不联网、不上云，可离线使用。打开默认进入「记一笔」页面，侧边栏共三个功能页 + 一个设置页。

在线访问：<https://wiannn.github.io/Accounting/>

## 功能

### 设置
- 导出 Excel 报表（收支明细 / 应收台账 / 收款记录 / 发票台账 / 工资表，5 个工作表）
- 备份与恢复（导出 / 导入 JSON 备份文件）

### 记一笔
- 月账本视图，顶部固定：统计月份、当月支出、当月收入
- 按日期分组显示当月所有收支流水
- 右下角圆形「+」按钮新增收支记录，支出支持主分类（仓库 / 车队 / 员工）+ 子分类
- 滑动切月：列表滑到底继续下滑 → 上个月；滑到顶继续上拉 → 下个月
- 金额框 / 备注框按回车即可保存

### 账单（应收 + 应付）
- 顶部「待收总额」「待付总额」汇总
- 应收：添加客户账期账单、登记收款、登记开票，状态 待收 / 部分收款 / 已结清
- 应付采购：登记供应商欠款（现结 / 周结 / 月结），登记付款时自动生成支出流水进「记一笔」，状态 待付 / 部分付款 / 已付清
- 客户管理（重命名 / 删除）
- 金额框按回车快速添加

### 员工工资
- 员工管理：按职位排序（叉车工 / 装卸工 / 司机 / 调度 / 操作 / 换单）
- 按月生成工资单，下拉框逐个选员工录工资
- 缺勤管理：当月日历点选，日期变红即缺勤，0 天显示「全勤」
- 工资状态：待发 / 部分发放（预支）/ 已发，支持多次发放记录
- 员工报销：登记员工垫付费用（如司机过路费），标记已报销后自动生成支出（员工 · 报销），支持撤销
- 工资单支持按姓名搜索

## 技术说明
- 纯前端单文件应用：`index.html`
- Excel 导出依赖外部文件 `xlsx.min.js`（SheetJS），与 `index.html` 同目录
- 数据存储：浏览器 IndexedDB，各设备数据独立，不跨设备同步
- 部署：GitHub Pages，`index.html` 需放在仓库根目录并命名为 `index.html`

## 数据安全
- 数据仅保存在当前浏览器中，清理浏览器数据会导致数据丢失
- 建议定期在「首页 → 备份与恢复」中导出备份文件，存放到 U 盘或微信文件助手
- 跨设备搬数据：在旧设备导出备份 → 在新设备导入备份

## 本地运行
直接用浏览器打开 `index.html` 即可，无需任何构建或服务端。
